# Jogo do Primata

Abra o `index.html` no navegador.

- **A / D** ou **setas**: andar · **W / ↑ / Espaço**: pular
- **L**: abre/fecha a loja · **Esc**: fecha a loja

## Loja

As moedas pegas nas fases ficam guardadas no navegador. Na loja dá para comprar e
equipar **skins** (cores do macaco), **chapéus**, **óculos** e **roupas**. Clicar de novo
numa roupa equipada tira ela.

Para usar sua imagem do macaco, coloque o caminho em `IMAGEM_PERSONAGEM` no começo do
script: ela aparece como a skin "Original".
